# ربات ویدیوی نیایش

ربات تلگرام برای نیایش. لینک یوتیوب را می‌فرستد، ربات می‌پرسد ویدیو می‌خواهد یا فقط صدا و با چه کیفیتی، بعد فایل را می‌گیرد و می‌فرستد.

لحن ربات گرم است: «نیایش جانم»، «عزیزدلم»، «چشم عشقم»، «قربونت برم».

ربات روی گیت‌هاب اکشنز روشن می‌ماند. کامپیوتر لازم نیست روشن باشد. هر نوبت حدود پنج ساعت گوش می‌دهد و بعد نوبت بعدی را خودش راه می‌اندازد. یک زمان‌بندی هر ۱۵ دقیقه هم فقط مراقب است که اگر زنجیره قطع شد، دوباره روشن شود. جواب معمولاً چند ثانیه طول می‌کشد. موقع عوض شدن نوبت ممکن است یکی دو دقیقه فاصله بیفتد.

مدت ویدیو سقف ندارد. ویدیوی خیلی طولانی هم رد نمی‌شود. سقف واقعی مال تلگرام و گیت‌هاب است، نه مال مدت.

## این ربات چه کار می‌کند

1. لینک یوتیوب را بفرست. `youtube.com`، `m.youtube.com`، `youtu.be` و شورتز قبول است.
2. ربات عنوان و مدت را نشان می‌دهد و دکمه می‌دهد: ویدیو ۳۶۰، ۷۲۰، ۱۰۸۰، بهترین کیفیت، یا فقط صدا.
3. بعد از انتخاب دکمه، دانلود جداگانه شروع می‌شود و ربات همان پیام را به‌روز می‌کند.
4. اگر فایل حدود ۴۹ مگابایت یا کوچک‌تر باشد، مستقیم داخل تلگرام می‌آید.
5. اگر بزرگ‌تر باشد، دو راه می‌دهد: کیفیت پایین‌تر، یا لینک دانلود.
6. لینک دانلود تا ۲۴ ساعت می‌ماند و بعد پاک می‌شود.
7. هر نفر هم‌زمان فقط یک دانلود دارد.

لینک سایت‌های دیگر قبول نمی‌شود. اگر لینک پلی‌لیست باشد، فقط ویدیوی اول گرفته می‌شود. پخش زنده رد می‌شود، چون فایل ضبط‌شده‌ای ندارد.

## سقف حجم

تلگرام برای ربات حدود ۵۰ مگابایت جا دارد. این ربات تا ۴۹ مگابایت را مستقیم می‌فرستد.

اگر بزرگ‌تر باشد:

- «کیفیت پایین‌تر» کیفیت را کم می‌کند و اگر لازم باشد با ffmpeg فشرده می‌کند تا زیر سقف تلگرام بیاید.
- «لینک دانلود» فایل را روی Release گیت‌هاب می‌گذارد. سقف آن حدود ۲ گیگابایت است.
- ویدیویی که حتی با کیفیت پایین از این سقف بزرگ‌تر باشد، مثلاً یک ویدیوی چندده‌ساعته، به‌جای تصویر، صدا را به شکل لینک می‌گیرد. تصویر آن روی این سرویس جا نمی‌شود. مدت را به‌خاطر طولانی بودن رد نمی‌کنیم؛ فقط اگر فایل واقعاً جا نشود، همان را روشن می‌گوییم.

ریپو عمومی است. کسی که لینک Release را داشته باشد می‌تواند فایل را ببیند. ربات همین هشدار را موقع فرستادن لینک می‌گوید. Releaseهایی که اسمشان با `yt-` شروع شود، بعد از ۲۴ ساعت با workflow پاک‌سازی حذف می‌شوند.

## یوتیوب گاهی جلوی سرور گیت‌هاب را می‌گیرد

دانلود از IP سرورهای گیت‌هاب بعضی وقت‌ها با پیام «Sign in to confirm you're not a bot» بسته می‌شود. این محدودیت یوتیوب است.

دو کار این‌جا شده است:

- هر بار دانلود، آخرین نسخهٔ `yt-dlp` نصب می‌شود.
- اگر Secret به نام `YT_COOKIES` گذاشته شود، همان کوکی برای یوتیوب استفاده می‌شود. کوکی را از مرورگر خودت، با فرمت Netscape، بگیر و فقط به‌صورت Secret بگذار. کوکی را داخل کد یا چت ننویس.

اگر این پیام آمد، ربات می‌گوید یک کم بعد دوباره امتحان کن.

## استفادهٔ شخصی

ربات برای استفادهٔ شخصی نیایش است و برای ویدیوهایی که اجازهٔ دانلودشان وجود دارد. ویدیوی خصوصی، حذف‌شده، یا محدود به سن را با پیام روشن رد می‌کند.

## چیزهایی که در ریپوی عمومی دیده می‌شود

این ریپو عمومی است تا اکشنز رایگان بماند. این‌ها را دیگران هم می‌توانند ببینند:

- شناسهٔ چت، داخل `state.json`
- لینک‌هایی که برای ربات فرستاده می‌شود، داخل `state.json` و ورودی اجرای دانلود
- فایل‌هایی که به‌خاطر حجم زیاد لینک می‌گیرند، تا ۲۴ ساعت روی Release

توکن ربات داخل کد، لاگ، یا فایل commit‌شده نیست. فقط Secret است.

اولین چت خصوصی‌ای که به ربات پیام بدهد ذخیره می‌شود و بعد از آن بقیه نادیده گرفته می‌شوند. اگر `ALLOWED_CHAT_IDS` را بگذاری، فقط همان شناسه‌ها جواب می‌گیرند.

## راه‌اندازی

این ریپو از قبل ساخته و وصل شده است. اگر خواستی از نو بسازی:

1. یک ریپوی عمومی بساز. ریپوی خصوصی برای روشن ماندن شبانه‌روزی رایگان نیست.
2. از BotFather یک ربات تازه بگیر و توکن را فقط به‌صورت Secret ذخیره کن.
3. Secretها را بگذار.
4. Actions را روشن کن.
5. workflow به نام Poll را یک بار دستی اجرا کن. بعد از آن خودش روشن می‌ماند.

### Secretها

در پوشهٔ ریپو، این دستور توکن را می‌پرسد. توکن را همان‌جا بچسبان و وارد چت یا فایل نکن.

```powershell
gh secret set BOT_TOKEN --repo yasinkeykha6060-sys/niyayesh-video-bot
```

قفل کردن چت، اختیاری. چند شناسه را با کاما جدا کن.

```powershell
gh secret set ALLOWED_CHAT_IDS --repo yasinkeykha6060-sys/niyayesh-video-bot
```

کوکی یوتیوب، اختیاری:

```powershell
gh secret set YT_COOKIES --repo yasinkeykha6060-sys/niyayesh-video-bot
```

### اجرای دستی

```powershell
gh workflow run poll.yml --repo yasinkeykha6060-sys/niyayesh-video-bot --ref main
gh run list --repo yasinkeykha6060-sys/niyayesh-video-bot --workflow poll.yml
```

در لاگ باید `watching` بیاید و همان مرحله روشن بماند. این یعنی ربات دارد گوش می‌دهد.

## تست

1. ربات را در تلگرام باز کن.
2. `/start` را بفرست. باید سلام کند و بگوید لینک یوتیوب را بفرست.
3. یک لینک یوتیوب بفرست.
4. یکی از دکمه‌ها را بزن: کیفیت ویدیو، یا فقط صدا.
5. صبر کن تا فایل، یا دکمهٔ کیفیت پایین‌تر و لینک دانلود، بیاید.

اگر جواب نیامد، چند دقیقه صبر کن و دوباره `/start` بزن. اگر تازه نوبت عوض شده باشد، فاصلهٔ کوتاه طبیعی است.
